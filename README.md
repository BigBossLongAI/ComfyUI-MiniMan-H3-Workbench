# ComfyUI MiniMan H3 Workbench

Independent three-stage workbench derived from `(AAA)MiniManH3（三采）`. Saved default size: 1158.83 × 1088.56.

Copy custom_nodes/miniman_h3_workbench and custom_nodes/h3-memory-guard into ComfyUI/custom_nodes, copy the bundled third_party packages into ComfyUI/custom_nodes, install their requirements and the remaining dependency in SOURCES.md, and open workflows/MiniMan-H3-Workbench.json after restarting ComfyUI.

Second and third sampling stages have separate toggles, step counts and resolutions. Reference images, video frames and audio can be uploaded internally or connected through growing optional sockets. The right-side preview shows the current sampler stage and step, then the final video with click-to-play controls.

Public workflow contains no private reference files or generated video records. Local originals remain untouched. Model filenames and settings are retained. Model binaries have not been uploaded; source and license verification is recorded in MODELS.json.
