# MiniMan H3 三采工作台

基于本机 `(AAA)MiniManH3（三采）` 的独立工作台节点，分类 `MiniMan/H3`，名称 **MiniMan H3 三采工作台**。

重启 ComfyUI 后打开另存的 `(AAA)MiniManH3（三采）_整体工作台.json`。原工作流没有修改。

- 一采始终执行；二采、三采分别开关，三个阶段分别设置步数。
- 关闭二采、启用三采时，三采直接放大并细化一采结果。关闭阶段不执行放大或采样，也不计入总调度步数。
- 默认参数与原流程一致：4 / 3 / 3 步，0.7 / 1 / 2 MP，24 fps。
- 素材直接在工作台内上传、选择和预览，也可外接加载节点。界面默认显示 9 个图片位、3 个视频位、3 个音频位；空位不加载、不参与编码。原示例的四张参考图和提示词已迁移到节点内部。
- 视频按 24 fps 读取，可单独选择是否参考视频原声。全部素材为空时可仅用提示词生成。
- 创作页显示提示词和实时采样预览；开关、步数和各阶段分辨率集中在「采样设置」。默认大小沿用最后保存的约 1159 × 1089，切换标签时保持大小，模型、LoRA、高级设置在内部滚动，保存前缀位于高级设置。
- 生成完成后，右侧预览区切换为带音频的成片播放器，需点击播放，不会自动播放。支持原生采样预览及 VHS 动态预览数据。
- 左侧提供可自动增加的图片、视频帧和音频输入，中文加数字标识；同编号外接素材优先。成片从右侧输出。视频原声开关位于内部视频素材卡片。
- 高级参数包含模型、三采 LoRA 及强度、注意力、FFN 分块、放大设备与精度、音频速度和保存质量。LoRA 选择 `None` 或强度设为零可禁用。
- 自动保存一个带音频的 H.264 MP4，并输出成片 VIDEO。

内部通过 ComfyUI 原生图展开调用原有加载、采样、放大及保存节点。需要已安装的 Video Helper Suite、潜空间放大器、音频速度节点、VRAMCleanup 和 H3 FFN 分块节点；没有新增依赖或下载模型。
